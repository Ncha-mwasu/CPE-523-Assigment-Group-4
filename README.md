# CPE 523 - Artificial Neural Network Assignment (Group 4)

This repository contains the CPE 523 assignment for Group 4. It includes a Jupyter Notebook (`Assignment_bank.ipynb`) that builds and evaluates various machine learning models (including a Neural Network/MLP) to predict bank telemarketing success.

## Prerequisites

To run this notebook locally, you will need:
1. **Python 3.x** installed on your machine.
2. The **dataset**: `mod_bank_additional_1.csv`. 
   > **Important:** Please ensure this CSV file is placed in the exact same directory as the notebook before execution.
